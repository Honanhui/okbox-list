# Java 依赖说明

runtime/cloud/lib 中的 JAR 为本服务编译和运行依赖，文件内保留原始 Maven 元数据及已有 NOTICE。

| 文件 | Maven 坐标 |
| --- | --- |
| json.jar | org.json:json |
| okhttp.jar | com.squareup.okhttp3:okhttp |
| okio.jar | com.squareup.okio:okio |
| zxing.jar | com.google.zxing:core |

发布时请保留随包 THIRD-PARTY-LICENSES 目录中的依赖许可。未为本项目新增整体许可证；参考项目和外部订阅不因本源码包改变授权范围。
